# RuleTrace Scholar Frontend

React 18 + Vite interface for paper upload, streaming academic Q&A, source inspection, and TRACE explanation reports.

## Commands

```bash
npm ci
npm run dev
npm run build
npm run lint
```

The `explanation` SSE event is rendered by `src/components/ExplanationPanel.jsx`. It shows the evidence-quality index, adaptive rule activations, claim-to-evidence mappings, and counterfactual improvement actions.
